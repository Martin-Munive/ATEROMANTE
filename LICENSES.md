## Documentation And Original Assets
Project documentation and original repository assets are available under Creative Commons Attribution 4.0 International unless a file states otherwise.

## Citation
Use `CITATION.cff` when citing the project in teaching, research, derivative software or public training material.

## Third-Party Dependencies
Third-party dependencies keep their own licenses. A dependency license report is planned before the first stable release.
