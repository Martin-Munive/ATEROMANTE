# Contributing

ATEROMANTE is in early design and spike development.

Useful contributions include:
- architecture feedback;
- accessibility feedback;
- chess-training workflow ideas;
- data model review;
- PGN/FEN import cases;
- local-first privacy improvements;
- documentation corrections.

## Development

Install dependencies locally:

```powershell
npm install
```

Run checks:

```powershell
npm run build
npm run lint
npm run qa:visual
```

## Public/Private Boundary
Do not add copyrighted books, private puzzle banks, private game archives, API keys, local databases, or private study material to this repository.

## Human Training Sessions
Features that assist players during human-vs-human games must be framed as consent-based training tools, not competitive assistance.
